# GARD M&A 관계자 공개·검토 웹앱 v2.0 — 배포 안내

**배포 범위:** Stage 0 공개 승인 요약과 Stage 1 지정 수신자가 **로컬에서** 불러오는 발췌 JSON만 지원합니다.

## GitHub → Netlify 배포

1. `GARD_MNA_PUBLIC_20261119.zip` 압축을 풉니다. `index.html`, `app.js`, `style.css`, `release.json`, `_headers`, `netlify.toml`, `README_MNA_KO.md`만 공개 저장소에 업로드합니다.
2. Netlify에서 GitHub 저장소를 연결하고, 프로젝트 루트에 이 7개 파일을 둔 경우 **Publish directory: `.`**, 별도 Build command 없이 배포합니다. 별도 폴더에서 업로드할 경우 공개 폴더만 배포 폴더로 지정하십시오.
3. 초기 `release.json`은 `items: []`로 비어 있습니다. Owner가 Stage 0 PUB-0 공개 범위를 확인하고 서면 승인하기 전까지 구매자 화면에는 제안 자산이 나오지 않습니다.
4. Owner 앱에서 **Stage 0 공개 안전 발췌 JSON**을 생성하고 사람이 재검수한 다음, 그 내용을 이 저장소의 `release.json`으로 **직접 덮어쓴 뒤 커밋**하면 Netlify에서 다시 공개됩니다.
5. 구매자는 공개 자산 요약을 검색하고 실사 질문을 작성하여 **JSON으로 내려받습니다**. 질문은 자동으로 Owner에게 전송되지 않습니다. 별도의 연락 채널을 사용하세요.

## Stage 1 NDA 검토

- 실제 NDA 체결, 승인된 수신자 신원, 열람목적, 만료조건을 외부에서 확인합니다.
- Owner가 만든 `GARD_MNA_PRIVATE_NDA_REVIEW_....json` 파일을 **공개 GitHub·Netlify·`release.json`에 올리지 않습니다**.
- 적법한 수신자만 자신이 보관한 M&A 웹앱 화면에서 **[Owner가 별도로 제공한 JSON 불러오기]**로 수동 가져옵니다.
- 체크박스는 수신자의 확인 문구이며 **NDA 서명·기술적 인증 또는 접근통제**가 아닙니다. 받은 파일은 복제 가능하고 임의로 회수할 수 없습니다.

## 명시적 제외사항

M&A 포털은 웹브라우저에 공개된 코드/JSON만 읽습니다. 개인 Owner 금고, IndexedDB 비밀 원본, 계약서 원문, 자격증명은 서버에 올리지 않으며 자동 접근하지 않습니다. 이 앱은 서명 전 데이터룸, 투자심사, 오너 내부 감사, 법적 증명, 비밀 문서 열람 승인 서버를 제공하지 않습니다. 그런 기능은 인증, NDA, 로그/워터마크, 시간 제한, 권한 철회 및 계약이 적용된 별도 서버 백엔드로 구현해야 합니다.

**주의:** 특정 데이터가 Stage 0에 들어간 순간 GitHub/Netlify 공개 배포가 가능하며 이후 되돌려도 이미 수집된 사본은 회수할 수 없습니다.
